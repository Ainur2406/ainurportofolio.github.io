Folder assets dipakai untuk menyimpan file pendukung website, misalnya:

1. foto-profil.jpg
2. gambar-proyek-1.jpg
3. gambar-proyek-2.jpg
4. icon atau logo

Cara ganti foto profil:
- Simpan file foto kamu ke folder assets
- Ubah bagian di index.html:
  src="assets/profile-placeholder.svg"
menjadi misalnya:
  src="assets/foto-profil.jpg"
